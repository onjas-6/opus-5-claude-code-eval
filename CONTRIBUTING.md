# Contributing

Independent replications, failure cases, and additional fixtures are welcome.

Please include:

- Claude Code version and requested/canonical model
- settings, skills, MCP, and permission-mode configuration
- exact fixture and hidden-grader logic
- repeat count and date/time window
- both task-correctness and process metrics
- a sanitized trace or machine-readable aggregate when possible

Do not commit credentials, account metadata, private prompts, or unsanitized machine-local session exports.
